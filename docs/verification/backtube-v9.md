# backtube v9 검증

2026-09-30~2026-10-01. ‘다음’ 첫 항목과 실제 다음 재생곡을 일치시켰습니다. 최종 사용자 교정대로 삭제한 곡의 재추천은 허용하고, 명시적으로 제외한 영상·채널은 추천에서 숨깁니다.

## 동작

- 현재 재생 대기열의 실제 다음곡 또는 추천 미리보기를 ‘다음’ 첫 항목에 표시합니다. 나머지 항목은 기존 추천 순서를 유지합니다.
- 현재 곡, 대기열에 이미 있는 곡, 교체로 건너뛴 추천 및 제외한 영상·채널을 추천 후보에서 거릅니다. 원본 캐시 메타데이터는 변경하지 않습니다.
- 곡이 바뀌거나 추천을 교체·제외하면 화면을 갱신합니다. 일시정지 중 마지막 후보를 제외해도 즉시 사라집니다. 회전 복원 시 오래된 목록이 다시 표시되지 않도록 갱신합니다.
- 후보가 모두 소진되면 정지합니다. 대기열에서 삭제한 곡은 다시 후보가 될 수 있으며, 계속 숨기려면 영상·채널 제외를 사용합니다. 수동 대기열과 명시적 반복 설정은 유지합니다.
- 닫힌 상세 화면의 플레이어 리스너와 지연 콜백도 정리했습니다. 별도 사용 기록 저장소나 의존성은 추가하지 않았습니다.

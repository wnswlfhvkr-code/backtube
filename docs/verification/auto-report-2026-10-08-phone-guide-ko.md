# backtube 로컬 오류 기록 테스트 앱 — 휴대폰 확인 안내 (2026-10-08)

## 1. 이 앱은 무엇인가요?

- 이름: **backtube 로컬 기록 테스트**
- 패키지: `org.schabi.newpipe.pr7faulttest20261008`
- 앱 버전: `1.0-pr7-local` (버전 코드 1)
- 디버그 전용 빌드입니다. 릴리스 빌드는 만들지 않습니다.

이 앱은 오류 기록이 **휴대폰 안에서만** 안전하게 저장되는지 확인하는 아주 작은 테스트 앱입니다.

- 실제 오류나 강제 종료를 일으키지 않습니다. 미리 정해 둔 가짜(합성) 오류 하나만 사용합니다.
- 인터넷 권한이 없습니다. 어떤 권한도 요청하지 않으므로 서버로 아무것도 보내지 않습니다.
- 글자를 입력하는 칸이 없습니다. 개인 정보를 넣을 방법이 없습니다.
- 기록은 이 앱 전용 내부 저장소(백업 제외 영역)에만 저장됩니다. 외부 저장소, 공유, 스크린샷 파일을 쓰지 않습니다.

이 앱은 **전체 재생 앱이 아닙니다.** 재생, 듣기, 뒤로 가기, 오프라인 보관함 같은 기능 확인과 실제 자동 수집·WorkManager·전송 확인은 별도의 전체 앱 검증에서 진행합니다.

아직 실제 휴대폰(API 23 / 35)에서 실행해 본 적은 없습니다. 이 안내가 첫 실행 절차입니다.

- 설치 화면에서 **"기존 앱 업데이트"** 라고 나오거나, 이 테스트 앱이 **이미 설치되어 있다면 즉시 멈추세요.** 덮어쓰지 마세요.

- 파일 설치를 위해 휴대폰이 "이 출처의 앱 설치 허용"을 물을 수 있습니다. 이때는 **설치에 사용하는 그 파일 앱 하나에 대해서만** 허용하세요.

## 3. 휴대폰 확인 순서

전체 과정은 **7일 안에** 끝내 주세요. 저장된 기록은 7일이 지나면 다음에 열 때 자동으로 정리됩니다.

1. **처음 열기**
   - 앱을 처음 열면 자동으로 로컬 기록 상태를 보여 줍니다.
   - 기대 결과: `기록 수: 0`, `민감 표식 없음: true`
2. **"합성 오류 저장" 누르기**
   - 기대 결과: `마지막 결과: ADDED` (새 기록이 저장됨)
   - `기록 수: 1`
   - 기록 내용: `"schema":1`, `"fault":"NULL_POINTER"`, `"component":"PLAYER"`, `"app_version_code":1015`, `"android_api":` 뒤에는 **지금 휴대폰의 실제 API 숫자**
3. **"같은 오류 다시 저장 (중복 확인)" 누르기**
   - 기대 결과: `마지막 결과: DUPLICATE` (같은 기록이 있어 새로 저장하지 않음)
   - `기록 수: 1` 그대로
4. **개인 정보 확인**
   - `민감 표식 없음: true` 인지 확인하세요. 아무 개인 정보도 입력하지 않았는지 확인하세요.
5. **강제 종료 후 다시 열기**
   - 설정 → 앱 → 정확히 **backtube 로컬 기록 테스트** (`org.schabi.newpipe.pr7faulttest20261008`) 를 찾아 **강제 종료**를 누르세요.
   - 삭제, 재설치, 데이터 지우기, 저장공간 지우기는 하지 마세요.
   - **같은 Android 사용자 프로필**에서 앱을 다시 여세요.
   - 기대 결과: 열자마자 `기록 수: 1`, 위와 같은 기록 내용이 그대로 보임
6. **다시 중복 확인**
   - "같은 오류 다시 저장 (중복 확인)" 을 누르세요.
   - 기대 결과: `DUPLICATE`, `기록 수: 1`
7. **"로컬 기록 다시 확인"** 은 언제든 눌러 현재 상태를 다시 볼 수 있습니다. 기록을 지우거나 초기화하는 버튼은 없습니다.

## 4. 결과 뜻

| 결과 | 뜻 |
| --- | --- |
| ADDED | 새 기록이 휴대폰 안에 저장됨 |
| DUPLICATE | 같은 기록이 이미 있어 저장하지 않음 (정상) |
| RATE_LIMITED | 하루 저장 한도에 걸림 |
| FULL | 기록 칸이 가득 참 |
| REJECTED | 합성 오류가 안전 분류를 통과하지 못함 |
| ERROR | 기록을 읽거나 쓸 수 없음. 기록은 지우거나 고치지 않음 |

기대와 다른 결과가 나오면 더 진행하지 말고 그 결과를 알려 주세요.

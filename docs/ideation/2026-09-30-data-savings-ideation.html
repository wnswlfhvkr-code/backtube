소리만 듣는 재생을 더 가볍게

오디오 전용 재생의 기반은 이미 있다. 추가 절약은 낮은 비트레이트 선택과 불필요한 다운로드 억제에서 찾는 것이 좋다.

현재 앱 소스를 확인한 아이디어 검토다. 앱 코드와 APK는 변경하지 않았으며, 실제 통신량·배터리 절감률은 측정하지 않았다.

Codebase Context · 현재 확인된 동작

백그라운드 플레이어는 일반적으로 별도의 오디오 스트림을 선택한다. 다만 오디오 스트림이 없으면 영상 스트림을 대신 쓰며, 생방송은 별도의 처리 경로를 거친다. 따라서 화면에 영상이 없다는 사실만으로 영상 데이터가 전혀 없다고 보장할 수는 없다.

데이터 제한 설정에는 낮은 비트레이트를 우선하는 로직이 이미 있다. 현재는 영상 해상도 제한과 묶여 있고, 기본 오디오 형식 선호가 비트레이트보다 먼저 적용된다.

이미지 품질 설정과 64 MiB 미디어 캐시도 존재한다. 새 엔진이나 새 캐시를 만들기보다 이 기능들을 재사용하는 편이 작고 확실한 변경이다.
